# Cropify
Cropify is a farmer-friendly web application that enhances agricultural productivity through advanced technology. The application uses React.js for a dynamic and intuitive front-end experience, while the back-end leverages Flask and machine learning models for intelligent data processing and predictions.

Key features:
1. Crop Recommendation: Cropify can be used to recommend the best crops to plant based on inputs such as location and levels of phosphorus (P), potassium (K), and nitrogen (N) present in the soil. It uses API (Application Programming Interface) keys to fetch temperature and humidity data based on the location, ensuring precise and context-specific suggestions.

2. Fertilizer Recommendation: Cropify offers customized fertilizer recommendations based on soil nutrient levels and environmental conditions to optimize crop growth.

3. Leaf Disease Detection: Cropify utilizes machine learning models to identify diseases from leaf images. Based on the disease detected, Cropify also recommends appropriate fertilizers and treatments to manage and cure the identified issues with the crop.
